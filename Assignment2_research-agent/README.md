# Autonomous Research Agent (LangChain)

## Objective
Build an AI agent that researches a topic and generates structured reports.

## Features
- Web search using DuckDuckGo
- Wikipedia knowledge tool
- ReAct-based agent (LangChain)
- Structured report generation

## Tech Stack
- LangChain
- Groq API
- Python

## How to Run
1. Create virtual environment
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python main.py

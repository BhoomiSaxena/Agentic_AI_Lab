This notebook demonstrates the complete process of fine-tuning a Small Language Model (SLM)
with fewer than 3 billion parameters on a text dataset sourced from Hugging Face. The task
is performed using Google Colab with GPU acceleration.

The workflow includes selecting an appropriate dataset and model, preprocessing and
tokenizing text data, configuring training parameters, fine-tuning the model using the
Hugging Face Trainer API, and evaluating performance using evaluation loss and perplexity.
Detailed explanations, results, and observations are included to provide clarity on each
step of the fine-tuning process.
